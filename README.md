# Tesla Tricks

A fan-made 3D stunt game based on the Tesla Roadster flight demo from October 2026. Launch up the C-shaped ramp, kick off the lip, then flip, roll and spin on cold-gas thrusters to keep your nitrogen tank full. Fly as far as you can before it runs dry.

Made by [Abdullah Sultan](https://amsultan.site). Not affiliated with Tesla.

## Play

Open `index.html` in a browser, or serve the folder with any static host (Vercel, GitHub Pages, Netlify). There is no build step. three.js r128 loads from the jsDelivr CDN, so the page needs an internet connection.

## Controls

| Key | Action |
|---|---|
| Space | Kick at the ramp lip, then rear boost in the air |
| W / S | Front flip / back flip |
| A / D | Barrel roll |
| Q / E | Flat spin |
| Shift | Level out |
| Right-drag, scroll | Orbit and zoom the camera (C resets) |
| Esc | Pause |
| M | Mute |

On touch screens, on-screen buttons appear automatically.

## Gameplay

- **Difficulty:** Easy, Medium or Hard sets starting gas, drain rate, hover strength and how forgiving landings are. Each mode keeps its own best distance.
- **Tricks:** frontflip, backflip, barrel roll and flat spin, plus combos (Corkscrew, Misty flip, Tornado, Triple axis) and style tricks (Inverted glide, Ground skim, Stratosphere, Nose dive). Chaining tricks raises the score multiplier.
- **Gates:** white (wide) gates give +28 bar, red gates +45 and blue (tight) gates +68.
- Land wheels-down or you wreck.
